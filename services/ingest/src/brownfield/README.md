# Brownfield

Parity pack y endpoints internos para MCP.

- `POST /internal/repositories/:id/brownfield-parity-pack` — MDD de un repo
- `POST /internal/projects/:projectId/brownfield-parity-pack` — MDD **fusionado** multi-root
- MCP: `export_brownfield_parity_pack` (`mergeProject: true` + `projectId` del workspace)
- Contrato: `docs/contracts/brownfield-parity-pack-v1.md`
